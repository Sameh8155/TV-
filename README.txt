IPTV Player - مشغل قنوات IPTV (Android / Android TV)

طريقة بناء الـ APK:
1) أنشئ مستودع جديد على GitHub وارفع كل محتويات هذا المجلد (بما فيه مجلد .github).
2) افتح تبويب Actions ثم Build APK ثم Run workflow (أو يبدأ تلقائياً عند الرفع).
3) بعد انتهاء البناء حمّل الملف iptv-player-apk من أسفل صفحة التشغيل (Artifacts) وفيه app-debug.apk.
4) انقل الـ APK إلى الجهاز وثبّته (فعّل التثبيت من مصادر غير معروفة).

لتغيير القنوات: استبدل الملف app/src/main/assets/iptv.m3u بملف آخر بنفس الاسم وأعد البناء.

التحكم على التلفزيون: أعلى/أسفل = تغيير القناة أثناء المشاهدة، رجوع = العودة للقائمة.
